# Documentación técnica — ERPNext Proposals

> Esta sección contiene documentación para administradores, implementadores y desarrolladores.
> La documentación de usuario final está en [docs/usuario/](../usuario/index.md).

## Índice (pendiente de desarrollo)

La documentación técnica cubrirá:

- Instalación y configuración del módulo
- Requisitos de sistema y dependencias
- Configuración de roles y permisos
- Descripción de DocTypes y esquema de datos
- Hooks implementados y puntos de extensión
- Print Formats: estructura y personalización
- Script Reports: filtros y datos disponibles
- Fixtures: qué se incluye y cómo actualizarlos
- Workflow: estados, transiciones y validaciones
- Guía para agregar nuevos Scope Items y Templates
- Integración con ERPNext (Activity Type, Cost Center, Project, Task)
- Troubleshooting y errores conocidos a nivel técnico
- Guía de contribución y convenciones del proyecto
